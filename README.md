# Shifr R-12

Учебный проект на JavaScript.

Проект содержит отдельные модули с логикой обработки данных и работы с запросами.

## Структура проекта

```text
shifr_R_12/
├── temp/            # Временные файлы
├── index.js         # Точка входа в приложение
├── request.js       # Работа с запросами
├── choslo.js        # Дополнительная логика
├── package.json     # Зависимости проекта
└── package-lock.json
```

## Технологии

* JavaScript
* Node.js
* npm

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/dalzhin1isp23/shifr_R_12.git
```

Перейдите в папку проекта:

```bash
cd shifr_R_12
```

Установите зависимости:

```bash
npm install
```

## Запуск

Команда запуска зависит от конфигурации в `package.json`.

После установки зависимостей используйте доступный npm-скрипт:

```bash
npm start
```

или выполните основной файл напрямую:

```bash
node index.js
```

## Статус

Учебный проект, созданный для практики JavaScript и работы с модульной структурой приложения.
